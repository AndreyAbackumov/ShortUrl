# Сокращатель ссылок на Scala. 
Это задание представляет собой учебный REST-сервис на Scala для сокращения ссылок.
## Документация.
Описание всех эндпоинтов находится в файле openapi.json в корне проекта. 
## Запуск проекта.
Для запуска проекта, введите в корне проекта: 
```text
docker-compose up
```
## Запуск тестов.
Для запуска тестов, введите в корне проекта: 
```text
sbt test
```

## Были реализованы следующие методы.
### POST /api/addUser
Эндпоинт для добавления пользователя.

### POST /api/addUrl
Эндпоинт для добавления ссылки. В ответе возвращается короткая ссылка. 

### GET /api/getLinks
Эндпоинт для получения списка: (короткая ссылка, начальная ссылка) для конкретного пользователя.

### GET /api/getPage
Эндпоинт для перенаправления по короткой ссылке.

## Использование коротких ссылок
Для перенаправления по короткой ссылке, нужно в браузере перейти по ссылке, указав логин пользователя и короткую ссылку. 
```text
http://localhost:8080/api/getPage?username=&&shortUrl=
```
